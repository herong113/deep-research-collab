# 文档版研究报告模板（document-report）
> 本文件防止的失败模式：报告缺模块、结论不挂证据编号、只给单一立场不给反证、来源与工具说不清、读者无法判断这份研究能不能信、也无法回溯。

用途：阶段 4 信息取舍与双格式输出时使用。本模板是**文档版研究报告（Markdown）**的骨架；单文件离线 HTML 交互式报告由同一份结构数据（`assets/report-payload-template.json`）渲染，**两版内容必须 100% 一致**。

填写总则：
1. 所有 `{...}` 为待填占位符；`示例` 前缀内容为示例数据，正式交付前必须替换。
2. 每条核心结论后必须标 `[EV-00X]`，编号与 `assets/evidence-library-template.md` 一一对应。
3. 拿不准的结论可信度标"待验证"，**不得**在概览里当作既定事实。
4. 禁止无来源结论、禁止伪造链接、禁止把"未检索到"写成"不存在"。

变量：`research_domain` = 研究领域；`audience` = 读者；`deliverable_target` = 交付目标；`stakeholder_view` = 关键干系人视角。

---

# {research_domain} 研究报告

> 副标题：{subtitle}　｜　读者与用途：`{audience}` — `{deliverable_target}`　｜　出具日期：{prepared_at}

1. {结论一} [EV-00X]

**证据充分度评级**

| 字段 | 内容 |
|---|---|
| 评级 | 充分 / 基本充分 / 不足 |
| 理由 | {为什么是这个评级：来源数量与类型、是否有一手来源、反证是否做完、缺口有多少} |
| 评级依据的缺口 | {未补上的缺口 ID 与影响} |

### 写作要求
- 概览必须先给判断，再给范围，最后给评级；不要写成目录。
- 评级口径固定：**充分** = 关键结论均有 ≥2 个独立来源且反证已做；**基本充分** = 关键结论有来源但部分为孤证或缺口未补；**不足** = 关键结论依赖待验证证据。
- 评级必须写理由，"评级：充分"单独出现视为不合格。
