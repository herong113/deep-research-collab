# 领域研究简报模板（domain-research-brief）
> 本文件防止的失败模式：在还没界定领域、没盘清本地能力的情况下直接开搜，导致研究主题漂移、证据不可复用、工具路线靠猜、后续阶段反复回退。

本模板在「阶段 0 研究初始化」填写。字段全部可为空值（写 `未知` / `待确认`），但**空值必须显式标注**，不允许留白，以免把"没查"误判成"没有"。

变量说明：`research_domain` = 研究领域；`audience` = 报告读者；`deliverable_target` = 交付目标；`stakeholder_view` = 关键干系人视角。

---

## 1. 原始意图

| 字段 | 填写说明 | 本次填写 |
|---|---|---|
| 原始请求原文 | 逐字抄录用户/需求方原话，不做改写 | {原始请求逐字原文} |
| 一句话意图 | 用「为谁、解决什么判断、达到什么程度」三段式写 | 为 `{audience}` 判断「{核心问题}」，达到「{可决策程度}」 |
| 决策用途 | 这份研究将被用来做什么决定（立项/投放/选题/课程设计/课题申报） | {决策动作} |
| 成败判据 | 满足哪些条件算这次研究"有用" | {判据 1}；{判据 2} |
| 截止时间 | 交付的硬时间 | {YYYY-MM-DD} |
| 不可接受结果 | 明确写出「即使信息齐全也不能出现的结论形态」 | {例如：只给观点不给来源 / 只给结论不给反证} |

**原始意图自检**：
- [ ] 能在 3 句话内说清这份研究要支撑哪个决定。
- [ ] 如果用户原话本身模糊，已记录"待确认项"而不是自行填空成确定结论。

## 2. 领域假设

领域假设 = 开搜之前我们对 `research_domain` 的全部先验判断。**每条假设都必须能被后续证据证伪**，否则不算假设。

| 假设 ID | 假设内容 | 依据来源 | 假设类型 | 证伪条件（什么证据能推翻它） | 验证状态 |
|---|---|---|---|---|---|
| H-1 | {示例：该领域主要由头部 3 家厂商定义标准} | 示例数据（用户口述，未核实） | 市场结构 | 找到 ≥2 份权威来源显示份额分散 | 待验证 |
| H-2 | {假设内容} | {来源或"无依据"} | 技术/政策/用户需求 | {证伪条件} | 待验证 |
| H-3 | {假设内容} | {来源} | 争议点 | {证伪条件} | 待验证 |

- 假设类型可选：市场结构 / 技术路线 / 政策监管 / 用户需求 / 成本结构 / 竞争格局 / 时间节奏。
- 验证状态只能填：待验证 / 已证实 / 已推翻 / 部分成立。
- **被推翻的假设不允许删除**，要保留在表内并进入阶段 3 反证记录。

**未知清单**（明确承认不知道的部分）：

| 未知 ID | 不知道什么 | 为什么重要 | 计划用哪一级搜索补 |
|---|---|---|---|
| U-1 | {未知内容} | {影响哪个结论} | 一级 / 二级 / 三级 |

## 3. 创建路线

创建路线 = 从"现在"到"可交付"的任务顺序，必须与五阶段流程对齐，并显式写出回退点。

| 阶段 | 本阶段要产出的东西 | 主要动作 | 进入下一阶段的通过条件 | 回退触发条件 | 预计成本 |
|---|---|---|---|---|---|
| 阶段 0 研究初始化 | 本简报、研究问题清单 | 界定范围、写假设、盘能力 | 意图与范围无歧义 | 意图仍模糊 → 回到与本简报填写人确认 | 0 次检索 |
| 阶段 1 广度候选检索 | 候选来源池（≥20 条；领域确实窄时 ≥12 条并附窄因说明） | 一级广度发现（`tvly` 全球域 + 秘塔中文域） | 候选池覆盖 ≥4 个独立来源类型 | 候选 < 20 条 → 换关键词再跑一级 | 约 3 积分/次秘塔检索 |
| 阶段 2 深度提取与认知地图 | 证据条目 + 认知地图骨架 | 二级深度核对（`mcp__metaso__metaso_web_reader`、`tvly extract`） | 每条候选要么产出证据，要么记录"取不到"原因 | 关键来源取不到全文 → 回阶段 1 找替代来源 | 按篇计 |
| 阶段 3 反证验证与缺口补全 | 反证记录、缺口清单、补全证据 | 主动找反证；三级缺口补充（微信公众号：秘塔搜索限定 `site:mp.weixin.qq.com` + `metaso_web_reader` 取全文） | 每条核心结论都有 ≥1 条反证检索记录 | 缺口补不上 → 降级该结论可信度而非删除 | 约 3 积分/次 |
| 阶段 4 信息取舍与双格式输出 | 文档版研究报告（Markdown）+ 单文件离线 HTML 交互式报告 | 取舍、统一编号、双格式生成 | 两版内容 100% 一致核对通过 | 两版不一致 → 回阶段 4 重新生成，禁止手工只改一版 | 0 次检索 |
| 阶段 5 证据归档与溯源备案 | 证据库归档、溯源备案、版本记录 | 冻结证据 ID、写归档信息 | 每个引用编号都能点回原始链接 | 链接失效 → 回阶段 2 补链或标注失效 | 0 次检索 |

**回退规则**：阶段 3 允许回退到阶段 1/2；回退必须在运行记录里写明次数与原因，不允许静默重跑。

## 4. 本地能力清单

填写前实际检查本机可用性，**不允许凭印象填"可用"**。证据列写你实际执行过的验证命令或观察结果。

| 能力 | 具体形态 | 本次是否可用 | 验证证据（命令/输出/观察） | 不可用时的降级路线 |
|---|---|---|---|---|
| 一级广度（全球域） | Tavily CLI 可执行文件 `tvly`（注意：命令名是 `tvly`，不是 `tavily`） | 可用 / 不可用 | `tvly --help` 输出 | 退化为仅秘塔中文域 |
| 一级广度（中文域） | `mcp__metaso__metaso_web_search` | 可用 / 不可用 | 一次试检索返回结果 | 退化为 `tvly` 单域 |
| 二级深度核对 | `mcp__metaso__metaso_web_reader`、`tvly extract` | 可用 / 不可用 | 取一篇全文成功 | 用摘要 + 标注"未取全文" |
| 三级缺口补充 | 秘塔搜索限定 `site:mp.weixin.qq.com` + `metaso_web_reader` 取全文 | 可用 / 不可用 | 命中 ≥1 篇公众号文章并取全文 | 标注缺口未补，结论降级 |
