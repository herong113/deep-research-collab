# 闭环运行记录模板（loop-run-record）
> 本文件防止的失败模式：每轮跑完只留一句"已完成"，意图、证据、可见结果、契约校验、决策和伤痕全部流失——下一轮从零开始，同一个坑再踩一次。

用途：`deep-research-collab` 每完成一轮运行填一份。一轮 = 一次从阶段 0 到阶段 5 的完整流转（或一次明确标注的局部运行）。

变量说明：`research_domain` = 研究领域；`audience` = 报告读者；`deliverable_target` = 交付目标；`stakeholder_view` = 关键干系人视角。

## 7. Scar Record（伤痕记录）

伤痕 = 真实踩过的坑，写清症状、根因、代价、修法，供下一轮直接避让。

| 伤痕 ID | 症状（观察到什么） | 根因 | 代价 | 修法 | 是否已写回 |
|---|---|---|---|---|---|
| SC-1 | {症状} | {根因} | 多花 {n} 次检索 / 结论返工 | {修法} | 是 / 否 |
| SC-2 | {症状} | {根因} | {代价} | {修法} | 是 / 否 |

**伤痕规则**：同一条伤痕出现 ≥2 次仍未写回，必须在本轮决策中至少给 `proposal`，不得再记 `none-with-reason`。
