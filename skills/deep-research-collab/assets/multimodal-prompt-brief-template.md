# 多模态与工具路线简报模板（multimodal-prompt-brief）
> 本文件防止的失败模式：技能包承诺了本地根本不存在的渲染能力或工具路线，等到要出图、出网页、出文档时才发现做不出来，只能临时降级或交付半成品。

用途：当 `deep-research-collab` 需要产出**非纯文本产物**（单文件离线 HTML 交互报告、图表、结构化 JSON 渲染）时，在动手前填写本简报。

变量说明：`research_domain` = 研究领域；`deliverable_target` = 交付目标。

---

## 1. 能力清单

填写前逐项**实际验证**，不允许凭印象填"支持"。证据列写实际命令输出或观察到的结果。

| 能力 ID | 能力 | 具体形态 / 调用方式 | 本次可用性 | 验证证据 | 降级路线 | 降级后果 |
|---|---|---|---|---|---|---|
| CAP-1 | 文本研究报告生成 | Markdown 文件 | 可用 | 生成并打开成功 | 无（必备能力） | 无法交付 |
| CAP-2 | 单文件离线 HTML 生成 | 内联 CSS/JS 的单 HTML 文件，无外链依赖 | 可用 / 不可用 | 断网打开、交互可用 | 内联简化版：仅目录锚点 + 表格 | 失去图表交互 |
| CAP-3 | 结构化数据渲染 | 从 `assets/report-payload-template.json` 读取并渲染 | 可用 / 不可用 | 解析 + 渲染成功 | 手写 HTML 片段 | 易与 Markdown 版不一致 |
| CAP-4 | 图表绘制 | 内联 SVG 或 canvas；`kind` ∈ {bar, line, pie} | 可用 / 不可用 | 生成一张示例图并肉眼确认 | 退化为表格 | 趋势不直观 |
| CAP-5 | 本地图像/媒体生成 | Image2 或宿主原生图像能力 | 可用 / 不可用 | 生成一张测试图 | 不使用图像，纯文本 + 表格 | 无配图 |
| CAP-6 | PDF / 打印输出 | 宿主原生导出能力 | 可用 / 不可用 | 导出并打开成功 | 仅交付 HTML（浏览器打印） | 需用户自行打印 |
| CAP-7 | 中文域检索 | `mcp__metaso__metaso_web_search` | 可用 / 不可用 | 试检索返回结果 | 仅全球域 | 中文源覆盖下降 |
| CAP-8 | 全球域检索 | Tavily CLI 可执行文件 `tvly`（命令名是 `tvly`，不是 `tavily`） | 可用 / 不可用 | `tvly --help` 输出 | 仅中文域 | 英文源覆盖下降 |
| CAP-9 | 全文深度核对 | `mcp__metaso__metaso_web_reader`、`tvly extract` | 可用 / 不可用 | 取一篇全文成功 | 用摘要 + 标注"未取全文" | 证据强度下降 |
| CAP-10 | 公众号缺口补充 | 秘塔搜索限定 `site:mp.weixin.qq.com` + `metaso_web_reader` 取全文 | 可用 / 不可用 | 命中并取全文 | 标注缺口未补 | 结论降级为待验证 |
| CAP-11 | 附件/文件读取 | 读取用户提供的本地材料 | 可用 / 不可用 | 成功读取一份文件 | 让用户粘贴文本 | 效率下降 |

**硬规则**：任何进入交付物的产物形态，必须在 CAP 表里有"可用"记录 + 验证证据；没有的，只能走降级路线并**在报告附录写明降级事实**。

## 2. 产物简报

| 产物 ID | 产物名称 | 形态 | 依赖能力 | 内容来源 | 一致性要求 | 验收方式 |
|---|---|---|---|---|---|---|
| D-1 | 文档版研究报告 | Markdown 文件 | CAP-1 | 证据库 + 报告 payload | 与 D-2 内容 100% 一致 | 逐模块比对 |
| D-2 | 单文件离线 HTML 交互式报告 | 单个 `.html`，断网可用 | CAP-2、CAP-3、CAP-4 | 同一 payload | 与 D-1 内容 100% 一致 | 断网打开 + 关键交互点一遍 |
| D-3 | 证据库（工作产物） | Markdown 表格 | CAP-1 | 检索与提取结果 | EV 编号与 D-1/D-2 引用一致 | 编号查重 + 抽检溯源 |
| D-4 | 归档与溯源备案 | Markdown 附录 | CAP-1 | 运行记录 | 与实际消耗、工具一致 | 与消耗记录核对 |

**产物规格（HTML）**

| 规格项 | 约定 |
|---|---|
| 文件数 | 必须单文件；图片/样式/脚本全部内联 |
| 外链 | 内容中的原始链接保留为可点击链接；**渲染本身不依赖网络** |
| 交互项 | 目录跳转、认知地图展开/收起、图表切换（若有）、证据编号悬浮/点击定位到证据库行 |
| 图表类型 | `kind` 只允许 bar / line / pie |
| 编码 | UTF-8，行尾 LF |
| 不做的 | 不做在线托管、不做接口请求、不做自动更新 |

## 3. 提示词变体

同一任务的多套提示词写法，用于对比效果并固化最优一套。

| 变体 ID | 变体名 | 适用场景 | 提示词骨架（可直接复制改写） | 已知代价 |
|---|---|---|---|---|
| P-1 | 精简版 | 单轮快速跑通 | "针对 `{research_domain}`，为 `{audience}` 产出 `{deliverable_target}`；先出研究简报，再跑三级搜索，最后出 Markdown + 单文件离线 HTML，两版内容必须一致；每条结论后标 [EV-00X]。" | 反证深度可能不足 |
| P-2 | 严格证据版 | 需要可溯源的正式交付 | "…每条结论必须挂 [EV-00X]；每个 EV 必须有原文片段与原始链接；找不到反证要写明'未找到反证'并说明检索范围；拿不准的结论可信度标'待验证'，不得升格。" | 耗时与检索成本更高 |
| P-3 | 反证导向版 | 论证已有倾向性结论 | "…先列出该结论可能成立的 3 个反例方向，逐个检索；正反证据并列后给出适用边界；禁止只收集支持性证据。" | 需要更多轮检索 |
| P-4 | 缺口补全版 | 中文一手材料缺失 | "…一级广度用 `tvly` 全球域 + 秘塔中文域；对中文实践类缺口，用秘塔搜索限定 `site:mp.weixin.qq.com`，再用 `metaso_web_reader` 取全文。" | 受公众号内容质量波动影响 |
| P-5 | 结构化直出版 | 直接生成 HTML | "…先把结论整理成 `assets/report-payload-template.json` 的结构，校验 `json.load` 通过后，用同一份 payload 同时生成 Markdown 与单文件离线 HTML。" | 需要字段口径严格遵守 |

**变体选择规则**：正式交付默认 P-2 + P-3；时间受限用 P-1 并在报告标注"未做完整反证"；中文实践型领域叠加 P-4；双格式交付必带 P-5。

## 4. 验证

| 验证 ID | 验证对象 | 验证动作 | 期望结果 | 失败处理 |
|---|---|---|---|---|
| VER-1 | 结构化数据 | 用 `json.load` 解析 `assets/report-payload-template.json` 与本次 payload | 解析成功 | 修语法后再渲染 |
| VER-2 | 枚举合法性 | 检查 `kind` / `type` / `credibility` / `layer` / 案例 `type` | 全部落在允许集合 | 改取值 |
| VER-3 | HTML 离线可用 | 断开网络后打开 HTML | 可打开、样式在位、交互可用 | 检查外链依赖并内联 |
| VER-4 | 双格式一致 | 逐模块比对 Markdown 与 HTML 文本 | 内容无差异 | 从同一 payload 重渲染 |
| VER-5 | 图表正确 | 抽查每张图的数据点与证据编号 | 数值与 EV 一致 | 修正数据源 |
| VER-6 | 编码与行尾 | 检查 UTF-8 与 LF | 无乱码、无 CRLF | 转码/转换行尾 |
| VER-7 | 降级声明 | 检查降级项是否写入报告附录 | 每个降级项都有声明 | 补写声明 |
